# Statement Lens v1.0.0

Statement Lens v1.0.0 is the first reproducible portfolio release of an educational,
provenance-first financial-statement analysis toolkit. It normalizes bounded facts, compares explicit
filing versions, applies declared accounting mappings, reconciles structural equations and evaluates
declared ratios without network access or binary floating-point arithmetic.

## Included

- Versioned schemas and canonical SHA-256 lineage for sources, policies, inputs and outputs.
- Filing/retrieval availability boundaries and explicit base/comparison restatement selection.
- Decimal-safe normalization with instant/duration, unit, scale and dimension invariants.
- Fact-level filing-history changes that retain both sides' provenance.
- Exact-identity ratio policies with declared missingness, zero-denominator and rounding behavior.
- Versioned mappings, aggregations and separate pass/fail/insufficient-evidence reconciliation states.
- CC0 synthetic evidence and reproducible wheel/canonical-sdist verification.

## Verification

CI runs Ruff, formatting, strict MyPy, tests, four independent evidence replays, two package builds,
archive-policy checks, offline isolated installation, dependency consistency, vulnerability audit and
checksum generation on supported Python versions.

## Claim boundary

All included filings, facts and results are synthetic correctness evidence. They are not real filing
analysis, accounting assurance, financial advice, investment research or evidence of production
reporting readiness. The package remains Beta.

## Important limits

The release has no live filing adapter, Inline XBRL renderer, authoritative taxonomy resolver, signed
artifacts, authenticated source provenance, governed storage, production telemetry or recovery evidence.
See `docs/releases/residual-risks.md`.
